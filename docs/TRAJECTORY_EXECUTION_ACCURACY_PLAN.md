# 轨迹执行关系准确性实施计划

日期：2026-09-05。范围仅包括轨迹投影、执行关系布局、折叠与已选内容可见性，以及相应状态统计；不改创建预算、Fold 压缩、权限和创建流程。

## 目标与约束

- 已展开 Turn 中的每一个已投影真实事件均有可检查的节点，不再只取首个模型与最后一条 assistant。
- Step 按真实事件记录排序，工具调用通过 callId 与结果配对。同批调用不等于已经证明并行执行；缺少信息时不推断因果。
- Fold/Cite 上下文保留原位置与来源。会话级已投影事件不因没有 Turn 而消失。
- 子代理没有真实内部事件时，不生成 SA · tN 虚构过程；返回卡只能引用真实结果，或明确提示结果不可用。
- 折叠数量、已选清单、Turn/子节点高亮、创建时发送的引用一致。返回别名不增加快照数量。
- 已结束调用不一直显示 running；运行、失败、取消与未知状态不显示为成功。失败数量按逻辑失败去重，不累计其所属 Turn。

## 任务拆分及依赖

1. A：事件投影与状态，gpt-5.6-luna / xhigh。负责 `src/trajectory.ts`、必要的数据字段、投影单元测试。核对 DSH 的实际 Turn/Step/request/header/tool/result 数据格式，修正生命周期、关联、稳定排序和失败去重。语义变化更新投影版本。独立核对发现 `readSurface` 不含生命周期事件，因此补充 `src/service.ts` 中轨迹专用数据入口及对应 Host 测试：轨迹总览、列表、详情、创建校验统一使用完整日志快照，排除压缩替换副本，不改普通 Seed 的 current-surface 语义。
2. B：纯布局模块，gpt-5.6-luna / xhigh。负责新布局模块及单元测试。输出节点、边、步骤分组和完整边界，分离实际事件与视觉别名，不增加可选择的虚构 Step 事件。
3. C：面板集成与选择可见性，gpt-5.6-luna / high。负责面板、样式和交互测试。接入 B，显示隐藏数量与步骤分组，增加已选清单的详情、定位及移除，维护现有选择和弹层交互。
4. D：主代理独立验收。检查 A/B/C 的组合结果、核对真实 DSH 事件定义、运行测试及完整验证。失败项另立有明确复现与验收条件的单个修复任务，交给指定 Luna high/xhigh 子代理，复验直至通过。

A 与 B 通过已有 step、callId、parallelGroup 字段协作；必要的新增字段由 A 公布。B 的布局接口先确定，C 可独立集成。不同任务限定文件所有权，保留工作区已有修改，不提交 Git。

## 验收矩阵

| 场景 | 必须满足 |
| --- | --- |
| 多步骤、多模型响应、中间 assistant 文本 | 全部展示，步骤顺序正确，工具不会跨步骤被画为同层分支 |
| 同批多调用、结果乱序到达 | callId 精确配对，不把结果当独立调用，不把同批说成确定并行 |
| 无 Step、孤立结果、会话级上下文 | 保守顺序、无节点丢失、无伪造关联 |
| 运行/成功/失败/取消/缺失结果 | 生命周期状态诚实、失败聚合不重复计数 |
| 子代理展开 | 真实返回详情可读、可选且只计一次；内部过程未知时无虚构节点 |
| Turn 折叠与选择 | 隐藏数量清楚，展开前后选择一致，全选/清除联动所有子节点 |
| 已选清单 | 能检查所有已选事件，定位展开原节点，移除同步部分选中态，清单与创建 refs 一致 |
| 查看焦点与选中状态 | 查看焦点跟随被点击节点，不产生永久选中高亮 |
| 弹层、预算、既有功能 | 取消后保留轨迹选择，不改变已有预算和 Fold/Cite 行为 |

## 验证方式

先运行各任务的针对性测试，再由主代理运行类型检查、lint、完整测试、契约检查、可移植性检查、构建和 manifest 冒烟测试。布局用确定性节点/边断言验收；交互用真实 React 组件及原生格式事件投影的集成样例验收。浏览器人工视觉验收若未实际执行，交付时单独说明，不将 jsdom 测试称为真实 DSH 浏览器 E2E。
